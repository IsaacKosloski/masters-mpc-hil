# Identidade visual — LABSEM

A identidade do laboratório é mantida no repositório **`labsem-brand`** (versão 2), não aqui.
Este repositório usa uma cópia fixada em [`slides/labsem-brand/`](../../slides/labsem-brand/README.md).

| O quê | Onde (no `labsem-brand`) |
|---|---|
| Marcas A (Lissajous) e B (Tela), em SVG, PDF, EPS e PNG | `assets/marca-a/`, `assets/marca-b/` |
| Paleta (grafite, marfim, cobre, azul noturno, pedra) | `assets/cores/` |
| Tipografia IBM Plex | `assets/fontes/` |
| Tema de slides de disciplina | `latex/beamer/beamerthemeLABSEMdisciplina.sty` |
| Guia do modelo de disciplina | `docs/latex/guia-modelo-disciplina-pt.md` |

> **Status:** proposta. A marca LABSEM é marca adicional de unidade e exige aprovação da coordenação
> do laboratório e da Agecom/UFMS via SEI. Uso restrito a divulgação e material didático, sempre com
> a marca UFMS, nunca em documentos oficiais.

A identidade v0.1 (símbolo "chip LS", Fira Sans, azul UFMS como primária) e o tema derivado do
AAU Sidebar foram substituídos — ver [ADR-0006](../adr/0006-tema-labsem-v2.md).
