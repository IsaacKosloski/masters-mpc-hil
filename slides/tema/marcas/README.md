# Marca UFMS

Coloque aqui os arquivos oficiais, baixados do site da UFMS (Manual de Identidade
Visual → download da marca), convertidos para PDF vetorial:

- `ufms-positivo.pdf` — marca colorida (fundos claros)
- `ufms-negativo.pdf` — marca em negativo (fundo azul do slide final)

Sem eles o tema compila normalmente, apenas sem a marca UFMS.
Não redesenhe nem altere a marca UFMS.
